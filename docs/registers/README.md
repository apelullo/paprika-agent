# Registers

Living lists whose rows have a lifecycle; the files never close. Correct in
place with a date; move closed rows to the file's Closed section; never reuse
a number. `deferred.md`: vetted items with a target stage or piece, reviewed
at every close for pull-forward (SOP.md section 4, step 2). `open_questions.md`:
questions that survived a pass, each naming what it blocks; an answered
question gets a DECISIONS.md line and moves to Closed.
