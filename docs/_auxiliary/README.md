# Auxiliary (temporary files)

Status-tagged proposals that survive pass boundaries but are not permanent:
design proposals feeding a future spec, process proposals, unvetted ideas.
Committed. Every file except this README carries, as its first three lines
after the title:

    **Status:** in-progress | closed
    **Closes when:** <criterion>
    **Last updated:** YYYY-MM-DD

While in-progress: replace in place; a change that is a decision gets a
DECISIONS.md line. Swept at every close (SOP.md section 4, step 7): an untagged
file is a defect; `closed` files move to docs/_archive/auxiliary/closed_<pass>/.
An `IDEA:` scratchpad entry may create the file it routes to.
