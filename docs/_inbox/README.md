# Inbox

Thoughts, tasks, and questions that surface after a pass closes and before
the next opens. One file per closed pass: `carryover_<pass>.md`, named for the
pass that produced it (the one just closed). Swept at every session start
(SOP.md section 2, step 3); archived with the pass that consumes it. Contents are
gitignored; this README is the tracked keeper.

Entry form: `- YYYY-MM-DD <chat|code|art> PREFIX: one line.` Post-reconciliation entries
moved from a scratchpad keep their disposition annotation.
